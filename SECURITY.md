# Reporting problems

This project modifies firmware only when you explicitly generate a local output file.
It does not communicate with or flash a keyboard.

For a software defect, open an issue with the model, stock firmware version,
tool version, settings and a description of the observed behavior. Do not attach
manufacturer firmware, modified firmware, USB serial numbers, credentials,
raw input logs or personal file paths.

Avoid running unknown firmware or third-party updater programs received in an issue.
If a report would expose private information, describe the issue without that data
and ask the maintainer for an appropriate private reporting channel.
